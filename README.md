# Wadeh · واضح

An Egypt-first real estate product. For a specific unit, it tells a buyer what the price buys, what is due on each date, whether the unit is still available, who confirmed it and when, which gate to use, and what changed since they last looked.

- Android app (Kotlin, Jetpack Compose, Arabic and English, RTL).
- Ktor API and operations console on PostgreSQL/PostGIS/pgRouting.
- Shared Kotlin core: money, cash-flow engine, parsers, contracts.

**Status:** pre-pilot software with **synthetic data only**. See `PROGRESS.md` (current state), `PRODUCT.md` (decisions), `ledger.json` (feature evidence), `docs/` (release, privacy and legal, pilot pack, research plan, economics), and `evidence/` (test and device evidence).
